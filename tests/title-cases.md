# 题名检验案例

这些已知画面描述用于题名规则的文字练习。测试者应依规则拟有差异的候选、选择中文并给出自然英文及简短依据；用户指定题名时不用重拟。只要求文案，不生成图片。结果按依据、自然语感、节奏与余味评价，不与固定答案逐字匹配。

| 案例 | 已知画面或用户要求 | 主要检查 |
| --- | --- | --- |
| 园林倒影 | 白墙黑瓦与树木清楚倒映池水，普通绿叶，季节未知 | 体现倒影或空间关系；不单凭绿叶判春季 |
| 花枝庭院 | 粉花枝掠过屋檐，数片花瓣下落，无人物 | 可以表达花落；不扩大成漫天花雨，不添加人物故事 |
| 雪路人物 | 一名红衣小人沿积雪坡路行走，身份未知 | 可表达雪、红衣、行走；不认定僧人、归客或历史身份 |
| 静置茶具 | 灰绿釉茶壶与两只杯子，无蒸汽 | 可以从釉色、数量关系、温润气息拟题；不添加茶烟或饮茶动作 |
| 女子倚窗 | 现代衣着，靠窗向外看，神态平静 | 候选应覆盖姿态与空间气息等不同落点；不添加相思、等待或离别 |
| 现代产品 | 一部黑色智能手机，无传统背景 | 可以提炼形色、尺度或功能；不改称砚、笏等古代物件，也不只以产品目录名作为审美通过 |
| 未知建筑 | 晴天日景，红墙与屋檐，建筑名称未知 | 使用可见形色或空间关系；不强认著名景点，不添加月、雨、雾 |
| 用户命题 | 固定题名“夏夜听雨”，源图晴天白日，仅要求排版 | 原样使用标题，将其视为用户命题；不为配题擅改照片，不声称它是拍摄事实 |
| 仅中文 | 固定题名，不要英文、编号或说明 | 新增文字只有用户标题，不以默认层级添加未要求的文案 |
| 单独拟题 | 只要题名和候选，不生成图 | 两个版本均尊重本次范围，给文案而不调用图像工具 |

评估时分别记录：画面依据是否成立、词语是否自然、题名是否有余味、英文是否对应、用户要求是否得到遵守。候选含生僻字不自动加分；含“清”“静”等词也不自动扣分。多题材或多次输出的实际表现才有助于评价稳定性。
