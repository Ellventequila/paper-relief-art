# 边缘颜料检验案例

观察真实输入与结果，分别检查局部色源、纸张吸收、疏密与主体稳定。文字模式不改变材料规则。

| 场景或要求 | 应采用的局部色源 | 主要检查 |
| --- | --- | --- |
| 上部松林，下部蓝青湖水 | 林梢附近用相邻树木的绿调；水岸附近用相邻水色 | 不把蓝色撒到树梢上方，不把绿色染满水岸；少量浅薄色痕可越出摄影边界，保留明显白纸间隔 |
| 红花与蓝色器物 | 花附近少量红染，器物附近少量蓝染 | 依相邻位置取色，不沿全部边缘混刷主色 |
| 黑白或低彩度建筑 | 相邻灰墨、灰白及原图已有淡色 | 不为装饰凭空添加鲜绿、朱红或金色 |
| 有字海报 | 主题边缘的局部源色 | 文字区和远处留白保持干净，题名、英文及排版不变 |
| 用户要求极干净外围 | 可减弱或省略独立滴斑，保留必要纤维着色 | 不为展示技法强制喷点 |
| 从已通过图片只修色痕 | 在既有纸浆与旁边平纸上着色 | 主体摄影核心与纸浆高低不重绘成厚模型 |

吸收性滴痕是哑光、薄透、不定形的染色：中心可稍浓，边缘有自然羽化、纤维洇开与少量颗粒沉积。部分染色纤维和白纤维交替，少数独立滴痕在紧邻纸面退散。不是规则实心圆章、凸起水珠、均匀点阵或满纸飞溅。

默认强度检查：正常观看能发现淡薄纤维渗色，缩略图仍先读主体与留白。若第一眼先看到深色滴点或成串色斑，应减淡、减量、拉开间隔；不以更多、更浓的颜料作为改进。

颜色更醒目不能单独证明优化成功。若主体变形、摄影感明显下降、材料变厚、文字改变或留白被填满，即使色痕漂亮也应记录为未完全通过。生成式编辑未必能保持文字区或材料区外逐像素一致，应以实际结果判断。
