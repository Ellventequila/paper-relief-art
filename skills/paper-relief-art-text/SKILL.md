# 纸境浮绘·有字版

将可辨认的摄影主体融入局部手工纸浆与矿物颜料，保留宽阔安静纸面。在留白中组织轻量中文题名、极小英文意译、短色线和少量辅助文字，形成完整的编辑排版层级。

本技能可独立使用，所需材料与模式说明均包含在本目录。用户最新明确要求优先；若要求无字，保留图像方向并取消新增文字，读 [无字模式](references/no-text-mode.md)。

1. 查看所有实际采用的素材，区分编辑目标与风格参考，忽略截图界面。
2. 读 [材料与构图核心](references/art-direction.md) 与 [有字模式](references/text-mode.md)。未指定题名时读 [题名创作与审美筛选](references/title-writing.md)，从画面关系拟候选、筛选并锁定中文及对应英文，再按 [提示词组织与修正](references/prompt-guide.md) 组织提示词。
3. 默认3:4竖版、约六成连通的安静纸面。保持主体真实细节与结构；在选定的外围建立可见纸浆脊、纤维交织和颜料积色—渗染—干刷露白，不满铺纹理。
4. 实际调用内置图像生成或编辑工具并传入用户素材，完成单幅作品。仅请求题名、候选、提示词或讨论时遵从其范围，不自动生成图像。
5. 查看成图，检查主体与留白、材料层级、删减条件和文字。明显偏差集中修正一次，继承全部已通过项。
6. 原素材不覆盖，按用户指定目录另存，按实际输出规格交付；图内不加水印、签名、工具名或制作标识。

默认采用修长轻量的中文宋体题名、明显更小的英文意译和短色线；主题眉题或侧字只作轻量呼应。用户要求纯中文或仅标题时相应精简。生成前写出所有新增文字，生成后分别检查字形、字号差、对齐、留白与文字准确性；不虚构编号、作者、日期或地点。
