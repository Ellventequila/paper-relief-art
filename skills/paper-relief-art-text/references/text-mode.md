# 有字版：完整而轻盈的编辑排版

主体与材质遵循同目录的材料核心。未指定题名时，先读 [题名创作与审美筛选](title-writing.md)，从可见主体、关系和细节拟候选并选定文案，再组织本页排版。用户最新的文字要求优先；要求无字时切换到无字模式，保留已经通过的画面。

## 默认排版不是只加标题

独立艺术海报默认建立三层阅读：修长轻量的中文题名 → 极小英文意译与短色线 → 极少量主题眉题或侧边文字。中文是视觉锚点，辅助文字提供节奏，连续留白仍然主导画面。

先了解可用的留白与文字区域；文案锁定后确定实际字号、分行、字重、对齐与间距，不为预设版式硬凑文字。不能把四个醒目的大字作为完整编辑排版的替代。参考中的价值是细笔画、字号差异、疏朗字距和统一对齐线，而不是复制作者的标签和编号。

## 文案与真实性

- 中文题名优先4字，合适时3—6字，一至两行；更长题名按用户要求或实际必要性处理。用户给定题名原样使用；未给定时依题名筛选规则从画面拟定古雅、自然、有依据的短题。
- 默认搭配简短、语义相关的英文意译，可分一至两行。英文不是无关口号，也不以大字重复中文的视觉重量。
- 可增加一处主题眉题或一处侧边／页脚微型文字，承载主体类别、主题或已知地点；不必两处都加。内容必须与图像相关。
- 编号可以作为用户要求的系列序号，但必须来自已定义系列或用户提供，不能随意照抄参考的“08”“09”或伪造作品档案。事实性的作者、日期、地点和说明同样只用已提供或核实的信息。
- “PAPER NOTES”“STUDY”、工具名称、作者签名、制作过程标签和截图界面不是默认作品内容。
- 生成前逐字列出本次所有实际文字；诗意内容与事实标签分清。

若用户明确不要英文，删除英文层，并调整空隙保持呼吸；不要用其他小字补满。若用户指定“只要这个标题，不要英文、编号或说明”，新增文字只有该标题，使用相同的轻量字形与对齐原则。若用户只要无字底图，所有新增排版文字与色线取消，保留原生标识。

## 字形与视觉重量

中文采用轻量、字面修长的现代宋体或明朝体印刷字形。横画细、竖画收敛、衬线清楚；字符留足内白。避免宽方且厚实的常规宋体、粗黑体、毛笔书法、机械拉长和装饰阴影。只写“纤细宋体”不足以约束结果，要同时说明轻量笔画、自然窄字面及整体文字组的尺寸。

标题优先使用低饱和暖炭灰、灰褐或中性墨色。原图强烈的蓝、红或金色主要给短色线，避免标题也成为浓色大块。字形清楚轻盈，不能把“可读”理解为增粗增黑。

英文及微型文字采用轻量窄无衬线，较小的字号、舒展字距和清楚行距；中英文有明显体量差，不能同样醒目。微型文字准确可读，不用伪字装饰。

## 一套可调整的竖版尺度

下表用于3:4竖版、两字一行的四字题名，是构图起点，不能机械套到八字长标题、横幅或小尺寸图片。

| 项目 | 起步尺度与关系 |
| --- | --- |
| 左侧基准线 | 距纸面左侧约9%—11%，中文、英文、色线共用 |
| 中文题名 | 上缘约纸面高度的11%—14%；单字高约画幅高度的4%—5%，字面宽约字高的70%—80%；两字及字距的总宽约画幅宽度的13%—17% |
| 中文行距 | 两行基线间距约字高的1.25—1.45倍，避免挤成方块 |
| 辅助英文 | 字高约中文的1/5—1/7，轻细、疏朗；不要为了填满标题宽度拉大字号 |
| 短色线 | 宽约画幅宽度的2%—3%，细且短，取源图一种颜色 |
| 主题眉题或侧字 | 比英文更轻或更小；只用一处至两处真正有作用的轻量呼应 |

标题和英文之间用“空隙—短色线—空隙”形成节奏，间距不必等分。文字与主体之间有一大片完整纸面，不能填满所有空白。眉题可以放在中文上方，侧字沿边缘读，不形成装饰框。位置随主体与留白改变，字号随实际输出和可读性调整。

## 文案与排版的衔接

例如画面中有窗与清晰枝影，题名规则可选出“一窗疏影”，英文承接为“SHADOWS ON THE WINDOW”。按自然语义决定分行，中文、极小英文与源图短色线共用对齐线；有必要时增加一处准确的主题眉题或侧字。

示例仅说明从画面关系到文案再到排版的过程，不作为固定题名与英文库。完整文字在生成前锁定，材料和构图不为文案凭空补景。

## 检查与修正

先看缩略图：文字组是否轻于主体、连续留白是否仍然完整、中文与英文有没有清楚的体量差。再正常观看字面是否修长、笔画是否轻、字距和行距是否疏朗、各行是否严格对齐。最后逐字核验新增文字与原生标识。

文字准确和排版好看是两个检查项，不能因为四字读对就判定排版通过。标题偏宽、偏粗、偏黑或只有孤立大字时，集中修正排版，不能同时重画主体、纸浆与颜料。文字出现错误时定点修正一次；仍有问题则说明实际限制，不将未通过结果称为完成。
