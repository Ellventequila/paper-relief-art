# 提示词组织与修正

先读同目录的材料核心。这里只规定提示词的必要内容，不提供需要机械整段复制的母版。

## 生成前的简短判断

确认用户要成图、提示词还是讨论；有真实素材时先看图。用户已授权创作时直接作出构图判断。

内部确定：
1. 编辑目标与每张参考图的作用；区分主体依据和风格依据。
2. 必须保留、允许简化、明确移除的具体内容。
3. 画幅、主体位置与大小、连续留白所在区域。
4. 摄影辨识核心、两三处纸浆交融位置、安静纸面的范围。
5. 每处主要交界的相邻景物与源色，颜料如何在现有纸浆上积色、吸收性渗染、干刷露白，并在紧邻纸面留下少量不定形滴痕；默认浅、少、疏：淡薄染色纤维为主，少量独立滴痕可选，染色之间保留明显白纸间隔；范围与密度服从留白。
6. 本次全部新增文字的逐字内容，或明确不新增文字。有字且未指定题名时，先依 [题名创作与审美筛选](title-writing.md) 提取画面依据、比较候选并锁定文案；用户只要求题名时不自动生成图。

把判断转成针对该照片的提示词，不将清单或占位符直接交给工具。主体描述、材料位置和颜料动作比空泛的“高级”“中式”“纸感”更重要。

## 提示词的顺序

- **输出与输入作用：** 单幅、画幅、编辑目标、其他参考图只负责什么。
- **主体锁定与背景取舍：** 具体形制、关系、关键色彩与删减清单。
- **构图：** 主体尺度与重心、连续留白位置；默认竖版约六成安静纸面，可按用户需求调整。
- **摄影与纸浆交融：** 哪些结构仍有摄影真实感，哪些选定部位长出纤维脊和纸浆薄片，哪些外围溶回纸面。
- **颜料行为：** 对每处交界指定相邻景物与局部源色，组织积色、稀释湿染、纤维渗透与露白；默认淡薄、局部、稀疏，仅一两处交界轻微渗染，可有极少量不定形浅色滴斑越出摄影边界，远处纸面保持洁净，不把一个主色沿全边均匀涂满。
- **光、纸、文字：** 平整纸面、柔和一致侧光、局部可见高低、模式要求的准确文字。
- **短禁项：** 只列本任务易出现的偏差，避免让长串禁项淹没正向材料描述。

## 建筑照片的具体示例：无新增文字

将天坛祈年殿照片作为建筑唯一依据，输出一幅3:4竖版纸上艺术作品。保留三层圆形屋顶的数量与比例、金色宝顶、朱红殿身、蓝绿彩绘和准确的原生匾额。删除游客、垃圾桶、告示牌及无助于主体表达的前景设施，台基保留足够层次支撑建筑。

整体海报的重心在中下部偏右，建筑本身维持中轴对称；上方和左侧形成连通的暖象牙白纸面，约六成画面安静。提炼台基外围，不把整张摄影背景铺满，也不把照片缩成矩形贴片。

屋檐、宝顶、彩绘与殿身的核心保留可信摄影细节和原图光色，不全面插画化。白石台基的一侧与下缘逐渐交织成哑光白纸浆，出现局部纤维团、浅纸浆脊和松散撕片，其他边缘仍清楚。纸浆起伏在普通观看尺度能辨认，薄层与几处微小堆积交替，直接生长在纸面上。

从殿身提取朱红，从屋顶提取蓝灰，少量色料顺台基纤维由贴近主体的极小积色变成淡薄、不均匀的洇染，再出现凸脊干刷、断开的色块和露白，最后退成稀疏细纤维。色痕有聚散，不环绕建筑描一圈，不扩大成铺满天空的水彩云。

留白基底平整洁净，只有近看才有的低密度纤维；柔和左上侧光在局部纸浆上形成细微一致阴影。只保留原生匾额，不添加标题、英文、编号、签名或任何其他排版文字。避免厚模型、重投影、主体变形、满铺裂纹及制作标识。

这是组织示例，不是对所有照片强制套用天坛构图或朱红配色。

## 有字模式的追加段

先读文字模式；未指定题名时读题名筛选规则，选定中文及对应英文，再确定短色线与真正需要的少量辅助文字，逐字写出内容。图像工具仅绘制已锁定文案，不自行改题或补诗。用自然窄字面、轻量笔画、明确的中文与英文体量差、文字组尺寸及共同对齐线约束排版，不能仅加孤立大标题。用户明确不要英文或只要题名时按要求精简，并保留同样的字形与空隙质量。首次从原始摄影创作时，完成主体、纸浆和颜料转换并组织文字；修改已通过底图的排版时，才明确只改文字区、完整继承主体与材料。有排版风格参考时实际传入，并标明不复制参考的主体或界面。

## 修正时的保留契约

每次修正都再次写出必须保留与明确移除清单、画幅、文字政策和已通过的构图。把修改限制到一个主要问题，继承已经删去的设施，防止原照片参照让杂物回流。

| 实际问题 | 下一次改什么 |
| --- | --- |
| 背景满铺粗纹 | 明确平整留白的位置，把可见纤维团限于交融区域 |
| 纸浆像石雕或模型 | 降低硬块与投影，改成软纤维束、薄片、断续沉积；仍保留局部高低 |
| 整体成了平面纸纹画 | 增加指定部位的纤维脊、接触阴影与颜料积色，锁定真实主体核心 |
| 只有抠图或毛边圈 | 打断边界，在少数位置让真实细节与带色纤维交叉 |
| 颜料像烟雾或水彩云 | 将颜色落在现有纤维与紧邻平纸，指定吸收性薄染、局部积色与露白，不增加纸浆厚度 |
| 外围全白或色料只停留在照片内 | 指定局部景物对应的源色，让少量染色纤维与不定形薄色滴痕进入紧邻纸面 |
| 滴斑过深、过密或抢主体 | 从已通过底图只修边缘，先稀释色料、减少数量与面积，保留白纸间隔，再调整羽化和不定形轮廓；不靠增加滴点证明颜料存在 |
| 滴斑像规则圆章或点阵 | 打散大小与距离，让色料沿纤维形成薄透、断续、不定形的吸收痕迹 |
| 边缘染色导致主体厚重重绘 | 回到已通过底图，锁定摄影核心、材料高低和文字，只给边缘纤维与近旁纸面着色 |
| 杂物回流或结构漂移 | 重申完整保留和删减清单；优先修准确性，不同时重排构图 |
| 排版错字 | 只修准确文字区域，完整继承画面和其他文字，不另添装饰 |

## 结果检查

缩略图检查连续留白、主体辨识和主次；正常观看检查摄影与纸浆是否各有特征、材料是否只聚在局部、边缘源色是否就近对应、滴染是否淡薄、稀疏自然，色斑之间是否有明显露白，是否退居主体之后；放大检查关键结构、文字、颜料是否沿纤维变化。核对删减清单，没有额外人物、截图界面、水印或制作标识。

若有主要偏差，针对主要问题修正一次。仍不达标时如实说明，不用继续加粗纹理或不断重绘掩盖失败。保存新文件，保留原素材；用户指定目录优先。交付工具实际输出的高质量原图，不虚称模型版本、分辨率或新增高清细节。
