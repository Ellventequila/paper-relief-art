# 题名创作与审美筛选

有字作品未指定题名时，先用本规则完成文案，再读文字模式组织排版。用户已给定题名时保留原文，只处理其要求的其他文案与排版。只请求题名或候选时交付文字，不自动生成图像。

目标是与这幅图相称的古雅短题：有可感知的物象或关系，语言自然，读来有节奏，意境留有余地。纸浆、浅浮雕和留白决定文案的克制程度；题意主要来自画面内容，不把每张都命名成“纸境”“浮绘”或“入纸”。

## 1. 先建立画面依据

以实际看过的素材和用户说明为依据，简要提取：
- **主体：** 建筑或局部构件、人物、器物、植物、山水等，抓住最有辨识力的一项，不罗列全部物件。
- **可见关系：** 花瓣落向庭院、屋檐映入水中、一人沿雪路行走、枝影掠过窗面等。动作、空间和映照关系常比单个物件更适合成题。
- **独特细节：** 色彩、形制、数量、姿态、局部光影或肌理。题名不必照写地名或物种名，可以由这些细节进入。
- **可投射的气息：** 空间疏朗、繁花明丽、雪地辽阔、器物温润等。依据画面选择，不把所有作品都归为清寂。
- **不能确认的内容：** 季节、时段、地点、人物身份、心理与故事。明确这些边界，不把猜测当作命题依据。

生成后的构图可以改变留白，题名中的关键物象或关系应仍在最终画面中可辨。不能为凑题名给图像补出新物象。

## 2. 从具体关系生出古雅语言

使用清楚的名词、动词和克制的状态词，让常见汉字有含蓄节奏。可以用“檐、庭、盏、径、影”等与主体相合的常用古典词，不强行把现代物件改说成古代器物。

题名可以来自不同方向，例如：
- 物象与光色：点出这幅图独有的形色或映照。
- 场景与动作：让一个真实动作带出空间。
- 局部与余韵：从窗、檐、盏、径等具体局部，留下未说尽的意境。

题名可以省略主体全名，以形色、尺度、关系或气息形成审美简称；读者不必仅凭四字识别出确切物件。比如黑色现代手机可由形色提炼为“墨色方寸”，不必直写“黑色手机”，也不把它改称古代器物。审美简称仍须有画面依据，不能靠漂亮词组添加新场景。

这些是选题方向，不是必须套用的句式。优先4字，合适时可用3—6字；更长题名用于用户要求或确有必要的内容。四字也不必都拆成两字加两字，先保证自然语义，再选择分行。

古风来自简练、语感和物象关系，不靠生僻字、拗口倒装、假典故或“古韵、禅意、梦境”等标签堆叠。“清、静、幽”等词可以使用，空间气息可以成为题名的余韵；只在它们替代了全部画面观察、使题名仅靠古风标签成立时重新拟题。不因一个题名简短或含情绪词就自动淘汰。朴素而贴切的题名优先于勉强炫技的词组。

## 3. 区分诗意与新增事实

空间可以显得寂静、开阔、温润或明丽，标题可含蓄表达这些气息。人物的经历和内心不能凭表情杜撰；平静倚窗不自动成为“思君”“归人”“离愁”。

月、雨、烟、雪、落花、行走等具象内容须在画面、用户说明或明确创作主题中有依据。普通绿叶不足以判定春季，静置茶具没有蒸汽就不写“茶烟”。已知季节和清楚的季节物候可以使用；无法确认时选择颜色、影、水、枝等已知特征。题名表达可见阳光或影子，不据此推断具体拍摄时刻。

适量拟人或比喻可以表达形态与气息，例如物象相映的关系；读起来若会被理解成确有其人、确有动作或历史事件，就需改写。古典词可以借用，不声称原创题名出自某位诗人。用户要求真实诗句或典故时核实原文与出处，不能凭记忆拼接；默认自行拟题，不主动增加检索与引文。

用户指定的命题或虚构创作主题属于授权内容，即使与源图的时段或天气不同，也保留其意图；不把它说成照片的事实描述，也不擅自改图以配合题名。仅请求排版时照要求排版。

## 4. 候选筛选

未指定题名时，内部拟3—5个有差异的候选，至少覆盖两个选题方向。候选在“说什么”上应有不同落点，例如动作、空间关系与形色气息；仅调换同一姿态的词序，或给同一个“清寂”换近义字，不算不同方向。记录每个候选的一句画面依据即可，不向用户输出冗长推演。

先剔除无图像或命题依据的具象、误识主体、虚构事实、错字、假典故及明显不通的词组。再依次比较：

| 检查 | 问法与取舍 |
| --- | --- |
| 贴图 | 能指出题名对应的物象、关系或关键细节吗？优先抓住这幅图的落点。 |
| 自然 | 用日常语感读一遍，词序与搭配是否通顺？优先常见字与自然表达，避免为四字硬凑。 |
| 节奏 | 朗读是否利落，停顿是否自然？不机械追求平仄或押韵，也不切断完整词语。 |
| 古雅与余味 | 是否含蓄、有画面，给观看留下空间？避免营销口号、解释性长句和空泛意境堆叠。 |
| 差异 | 换成完全不同题材仍原封不动成立吗？若只能靠“国风感”成立，优先更具体的候选。相近题材允许共享词，不强求唯一。 |

选择一个在画面依据和自然语义上扎实、读来简洁且有余韵的题名。通过依据与语义的边界后，再按作品气息选择更凝练、有余味的表达；信息更直白不自动胜过含蓄。比如平静倚窗可以写姿态“倚窗而望”，也可写空间气息“窗畔清宁”，后者不因动作信息较少而被淘汰。准确是边界，不能成为只写物件目录或产品标签的理由；若候选全是说明性名称，再从形色、尺度或关系提炼一组，而不是直接把最保守的标签当作审美通过。标题过于直白时提炼措辞，不增添故事；过于抽象时回到一个可见物象或关系。候选都不理想时，换选题方向重拟一组，再选最稳妥的表达。不要以自评分数冒充客观审美证明，也不承诺每次得到“完美题名”。

同批作品再检查重复的核心词与句式，避免全部“某某清影”“某某清寂”。主题相近时用不同的真实细节形成变化，而非强行换生僻字。

## 5. 中英文与辅助文案

先锁定中文，再写短英文。英文应自然、简短地承接中文的关键物象、关系或中心意境；允许意译，不逐字搬运古典语法，不另加中文与画面都没有的季节、天气、人物故事或神秘含义。

英文通常2—6个词，按自然词组分成一至两行；专有名词或用户文案按实际需要处理。涉及主体名时使用已知准确名称，不把未知建筑冠以知名地名。独立检查英文是否只是漂亮但无关的口号，中文与英文是否仍讲同一幅图。删繁就简，避免为填满版面添词。

主题眉题与侧字仅提供轻量类别、主题或已知地点信息，不成为第二个无关故事。用户只要中文时，不生成英文或其他未经要求的文案。

## 6. 锁定文字与最后核对

选定后，在图像提示词中逐字写出中文、英文及实际采用的辅助文字和分行。图像工具负责绘制已选文案，不再自行改题、补诗或添说明。

成图后分别检查：
- 关键物象或关系是否仍在，题名有没有与实际结果脱节。
- 中文、英文和原生标识是否逐字准确；分行有没有截断语义。
- 排版是否通过文字模式的字形、层级、对齐与留白检查。

默认交付一个最终题名及成图；用户需要讨论时，再给少量候选与简短依据。

## 小例：依据决定用词

| 已知画面 | 可成立的题意 | 应舍弃的方向 |
| --- | --- | --- |
| 枝影落在窗面，季节未知 | “一窗疏影”：窗与枝影关系 | 无依据的春、秋、雨或离别故事 |
| 白墙黑瓦清晰映入池水，普通绿叶 | “檐影入池”：池水与屋檐倒影 | 单凭绿叶命名春色 |
| 一人在雪路行走，身份未知 | “雪径独行”：环境与动作 | 将红衣小人认定为僧人、归客 |
| 青绿色釉茶具静置，无蒸汽 | “一壶双盏”：器物的数量关系 | 添加“烟起”“沸香”或人物饮茶动作 |

这些是边界与语感示例，不是固定标题库。实际材料更丰富时选取更有辨识度的关系；现代产品可以保持简练古雅的语感，准确表达其形色或功能，不把名称强行写成传统器物。
